# Beslutningslogg (ADR)

Viktige valg dokumenteres som korte *Architecture Decision Records* (ADR). En ADR forteller hva som ble valgt, hvorfor og hvilke alternativer som ble forkastet. Da kan nye bidragsytere og «framtidige deg» forstå valgene uten å gjette.
