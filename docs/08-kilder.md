# 08 – Kilder og leseliste

Kildelisten ble satt sammen i forstudien i oktober 2026. **De fleste nettsidene er funnet via søkeresultater og er ikke lest i sin helhet.** Kilder på GitHub er lest direkte. Viktige tall bør sjekkes i originalkilden før vi bygger på dem. Legg gjerne til nye kilder med en kort merknad om hva den er nyttig til.
