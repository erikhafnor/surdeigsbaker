# Data

- `bakelogger/`: én fil per baking (`ÅÅÅÅ-MM-DD-kortnavn.md`) etter [malen](../docs/maler/bakelogg.md), eller lenke til et issue
- `bilder/`: bilder med dato i filnavnet (`ÅÅÅÅ-MM-DD-kortnavn-snitt.jpg`)
- `eksperimenter/EXX/`: rådata (CSV) per eksperiment. Første rad har kolonnenavn med enhet, f.eks. `tid_s,deigtemp_C,heving_mm`.

Hold filene små. Store videoer lenkes i stedet for å lastes opp.
